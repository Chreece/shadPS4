# shadPS4 — permanent universal emulator development contract

Effective 2026-10-26. The shared engine must work for all games without title, shader-hash, GPU-address or per-game compatibility exceptions.

**Branches.** Upstream `shadps4-emu/shadPS4:main` is checked before every integration/build. Fork `main` is the shared base of tested generic fixes, not a dumping ground for experiments. One canonical game progress tree per game: `got/proven-progress-20261026`, `gow/proven-progress-20261026`. New titles use `games/<slug>/progress`. Keep separate experimental worktrees disposable but archive their unique commits and results. No direct whole-game-ancestry merge to main. PRs for each isolated proven fix or reviewed prerequisite series; don't call an open PR "merged". Rebase onto the *latest* upstream plus all previously accepted fork-main repairs, using isolated worktree, with conflict resolution and regression tests before advancing main.

**Evidence.** After every test (including failed build, preflight, crash, identical visuals, rollback and rejection) append to [TRIALS.jsonl](TRIALS.jsonl) and the corresponding game diary. Include SHA-pinned upstream/source/binary and artifact hash, exact generic code change, compile/runtime results, measurements, *separate game graphics/audio/FPS outcome*, decision, PR, and falsifiable next step. Never edit or remove failed records; append a correction if needed. Visual change is not required to KEEP a proven generic correctness fix. Changing sampled warning counts in different scenes alone is not proof.

**Immutable tests.** Preserve last gameplay-capable GoW ELF SHA256 `8de2106a3e0d410904d9c8d6a2903ba6f1f65986af3c848b0bf274a4f4b45c8e`, native Oct26 compile-only ELF SHA256 `3e5c8c3f15d29313f20db584673c10fd52d581ed1f370ecf62fb8bc5dfbc3947`, plus protected GoT baseline specified in [GoT baselines](../got/BASELINES.json). New games use *exactly the same* emulator binary, renderer, native CPU path, standard fullscreen/FPS. **DynamoRIO rejected**; no `--cpu-id-mode`, fake CPU/GPU values, shader-hash workarounds, readbacks for one game or skipped draws. Keep loading splash and controller GUIDE -> confirm/cancel quit support in every build.

**Safety.** All game tests must automatically terminate only their own game process in 118s TERM + 2s KILL, never close SSH or change Sunshine, ES-DE, original saves and configs. If GPU free VRAM <8 GiB, unload *only* loaded Ollama models through localhost API, remember model/context/keep-alive and restore after the game exits; no Docker/host stop. Bound archives while keeping full source logs on host. Native compile, GPU/lifetimes, same-scene visual and cross-title regression must pass before main promotion.

**Cleanup.** Inventory *all* branch SHA refs and open PR head/base before deletion. Keep current/main, upstream, canonical GoT/GoW, game source/binary checkpoints, PR refs, any unmerged unique commits. Only prune proven redundant branches after snapshot, SHA recheck, confirmed no active worktree/build, and retained PR/evidence. Never silently delete unreviewed branches.
