## 2026-10-26 — PR79 source audit rejected naive per-gap allocation; packed plan replaces it

The **initial** PR79 physical allocation prototype (`4f0596d14b5b126de695e45c591daf8319a9f4b5`) was **REJECTED before any native GPU experiment**: it would create one VkDeviceMemory allocation for each small sparse guest-VA gap. BDA device addresses and page table copy offsets use the original GPU VA.
