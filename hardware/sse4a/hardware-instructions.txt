SSE4a hardware probe (OpenOrbis, x86-64 PS4)

This archive contains an unpacked homebrew SELF, its SFO, linked ELF, and source.
It is not an installable PKG. Use your existing PS4 homebrew packaging/launch
workflow with SSE400002/eboot.bin and SSE400002/sce_sys/param.sfo.

Run once on an actual PS4. No controller input or case-selection file is needed.
The probe runs all 84 EXTRQ/INSERTQ cases and exits automatically.
Retrieve /data/sse4a-hardware-result.txt through your normal homebrew file access.
The file is replaced on each run. Include the console model and firmware when
returning it. No game, save data, network access, or CPU hotplug is used.

The log records raw destination bits 255:192, 191:128, 127:64, and 63:0 separately,
plus CPU identification, per-form counts, and checks of defined results/state.
Undefined XMM upper bits are observations, not pass/fail assertions.
A complete run has 84 RAW lines, 8 CASE lines, and SSE4A_HARDWARE_END result=0.
A SKIP or missing completion marker does not count as a hardware result.
An emulator run is only a packaging smoke test, not proof of PS4 behavior.

Rebuild with OpenOrbis v0.5.4, Clang/LLD 19:
  make console.bin OO_PS4_TOOLCHAIN=/path/to/OpenOrbis/PS4Toolchain
  python3 package.py --hardware
For a native Linux observation using the same assembly:
  make native-probe
  ./native-probe
