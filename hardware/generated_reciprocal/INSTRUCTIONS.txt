CPU execute-permission tests — Linux x86-64

Keep games closed, then run: python3 run.py --cpu-only

This updates the separate test build using your existing cache and runs every check automatically. You do not need to launch PES, use the controller or change the session guard. The installed emulator and original game profiles are preserved.

The checks cover protected reads/writes, 64 high-address map/unmap cycles per mode, initial and cached non-executable code, page-crossing instructions, fallthrough and an untaken branch. They run in native and translated modes. The generated reciprocal probe also checks 121856 rows against the PS4 reference, eight boundary reads, eight recovered memory faults and allocation cleanup.

The two execute-permission failures from version 3 are fixed in this candidate. Missing faults are now rejected, with no known-failure exception. The extended checks also found and fixed a native instruction-patcher hang on a page with no access.

Upload only the .tar.gz named by UPLOAD_ONLY. Ctrl+C stops only this test and collects evidence; SSH stays open. Progress is printed while building and running.

Running without --cpu-only retains the optional two-stage PES comparison. It uses the existing session guard and controller quit handling. This package does not require that comparison for the execute-permission checks.

To rebuild a probe, use its Makefile with OpenOrbis:
OO_PS4_TOOLCHAIN=/path/to/PS4Toolchain make ORBIS_CXX=clang++-19 ORBIS_LD=ld.lld-19
The additional execution probe is in execute_permission/.
